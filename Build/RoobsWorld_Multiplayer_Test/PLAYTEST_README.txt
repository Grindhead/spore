How to test:
1. Extract the zip before running the game.
2. Run RoobsWorld.exe.
3. If Windows Firewall prompts, allow network access.
4. On one computer, choose Host Session and share the session code.
5. On another computer, choose Join Session and enter that code.

Keep the exe next to the RoobsWorld_Data, D3D12, and MonoBleedingEdge folders.

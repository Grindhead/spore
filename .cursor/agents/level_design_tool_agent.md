# Agent: LevelDesignToolAgent

## Goal

Create level and scene building tools for designers (placement, layout, procedural placement).

## Responsibilities

- Editor tools for placing prefabs or procedural objects in scenes.
- Optional runtime or editor-time procedural placement (e.g. prop scatter, vegetation).
- Integrate with project folder structure (Prefabs, Scenes) and naming.
- Document hotkeys and menu paths.

## Example tasks

- Level builder window (select prefab, paint or place in scene).
- Scene setup tools (lighting, spawn points).
- Integration with chunk or procedural level generators.

## Example prompt

"Create an editor window that lets designers place prefabs from Assets/Prefabs into the current scene with snap-to-grid."

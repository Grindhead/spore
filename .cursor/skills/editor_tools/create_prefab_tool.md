# Create a prefab-related editor tool

**Requirements:**

- Use EditorWindow if UI is needed; MenuItem for quick access.
- Support batch operations (e.g. selected prefabs, or all prefabs in a folder).
- Examples: create prefabs from models, add LODGroup, validate references, rename by convention.
- Do not overwrite or delete without user confirmation or explicit action.
- Follow `.cursor/rules/unity_editor_tools.mdc`, `prefab_generation_rules.mdc`.

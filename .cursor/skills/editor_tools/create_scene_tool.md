# Create a scene setup or scene-related editor tool

**Requirements:**

- Tool for scene setup (e.g. add required objects, lighting, spawn points) or scene list (e.g. add to Build Settings).
- Use project scene names and paths from `memory-bank/systemPatterns.md` (MainMenu, CellStage, etc.).
- MenuItem for access; optional batch or template application.
- Do not modify scenes without user action; follow `.cursor/rules/unity_editor_tools.mdc`, `unity_scene_structure.mdc`.

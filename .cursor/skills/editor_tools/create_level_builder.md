# Create a level builder or scene placement tool

**Requirements:**

- Editor window or tools for placing prefabs/objects in the scene (e.g. paint, place, snap-to-grid).
- Use prefabs from Assets/Prefabs; respect project folder structure and naming.
- Optional: integrate with procedural placement (seed, density) for prop scatter.
- Document menu path and usage; follow `.cursor/rules/unity_editor_tools.mdc` and `unity_prefab_rules.mdc`.

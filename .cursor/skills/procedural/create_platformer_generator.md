# Create a procedural platformer or level generator

**Requirements:**

- Deterministic seed; configurable parameters (length, difficulty, platform density, etc.).
- Chunk or section-based generation so level can stream or grow.
- Place platforms/obstacles via prefab or procedural mesh; use project naming and Prefabs folder.
- Optional editor preview; follow `.cursor/rules/level_generation_rules.mdc`, `procedural_generation_rules.mdc`.

# Create a Blender Python script

**Requirements:**

- Apply transforms before export or processing.
- For export: FBX format, scale 1, naming _VIS/_COL/_LOD0/_LOD1/_LOD2.
- Optional: generate LOD meshes, export to Unity project path (e.g. RoobsWorld/Assets/Art/Models).
- Follow `.cursor/rules/blender_export_rules.mdc`, `blender_asset_rules.mdc`. Use Blender MCP when available (see .cursor/README-mcp-blender.md).

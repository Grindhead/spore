# Generate a Blender LOD generation script

**Requirements:**

- Duplicate mesh and decimate (or simplify) for LOD1, LOD2.
- Name with _LOD0 (highest detail), _LOD1, _LOD2.
- Apply transforms; export as FBX or keep in scene for single export with multiple objects.
- Follow `.cursor/rules/lod_generation_rules.mdc`, `blender_asset_rules.mdc`.

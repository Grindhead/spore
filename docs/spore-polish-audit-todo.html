Cell, Creature Creator, and Creature Stage Spore-Like Polish Plan

Goal: deepen the existing Cell and Creature scope until it feels much closer to classic Spore's cell-to-creature arc, while preserving the multiplayer work already in the project: larger sessions, invite flows, remote player readability, lobby readiness, host migration, voice proximity, and player-count scaling.

Created: 2026-05-18 Scope: Cell stage + Creature creator + Creature game mode Guardrail: no later-stage expansion in this pass Verification baseline: latest EditMode XML shows 1204 passed, 0 failed Working-tree inputs included: TestResults/EditMode.xml plus current untracked files

Audit Snapshot

Strongest Foundation

The codebase already has a substantial Cell stage, a procedural Creature creator, generated creature part assets, a playable Creature arena loop, and meaningful multiplayer systems.

Biggest Risk

The cell growth to evolution to creature transition loop appears disconnected from normal play. There is UI for evolution, but the food-driven trigger path is disabled.

Main Fidelity Gap

Cell and Creature modes have systems, but they still read more like arena/action prototypes than an organism editor plus ecosystem progression loop.

Preserve

Keep unlimited-player session goals, scaled resources and rivals, lobby flow, remote cell ghosting, player mass labels, voice proximity, and host migration work.

Scope guardrail: do not add Civilization, Tribe, Space, or other later-stage features in this pass. The best return is to make Cell and Creature feel cohesive, expressive, readable, and multiplayer-ready.

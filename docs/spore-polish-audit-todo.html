Cell, Creature Creator, and Creature Stage Spore-Like Polish Plan

Goal: deepen the existing Cell and Creature scope until it feels much closer to classic Spore's cell-to-creature arc, while preserving the multiplayer work already in the project: larger sessions, invite flows, remote player readability, lobby readiness, host migration, voice proximity, and player-count scaling.

Created: 2026-05-18 Scope: Cell stage + Creature creator + Creature game mode Guardrail: no later-stage expansion in this pass Verification baseline: latest EditMode XML shows 1127 passed, 0 failed Untracked inputs included: TestResults/EditMode.xml

Audit Snapshot

Strongest Foundation

The codebase already has a substantial Cell stage, a procedural Creature creator, generated creature part assets, a playable Creature arena loop, and meaningful multiplayer systems.

Biggest Risk

The cell growth to evolution to creature transition loop appears disconnected from normal play. There is UI for evolution, but the food-driven trigger path is disabled.

Main Fidelity Gap

Cell and Creature modes have systems, but they still read more like arena/action prototypes than an organism editor plus ecosystem progression loop.

Preserve

Keep unlimited-player session goals, scaled resources and rivals, lobby flow, remote cell ghosting, player mass labels, voice proximity, and host migration work.

Scope guardrail: do not add Civilization, Tribe, Space, or other later-stage features in this pass. The best return is to make Cell and Creature feel cohesive, expressive, readable, and multiplayer-ready.

Recommended Implementation Order

Step Area Outcome Why this order
1 Cell progression Eating to growth to evolution to Creature works from a fresh run. This is the main spine of the whole two-stage game. Polish cannot land if the core arc can soft-lock.
2 Multiplayer authority Shared ecology, evolution milestones, and stage transitions are deterministic. This protects the multiplayer improvements while every later gameplay feature is added.
3 Cell editor and organelles Player choices visibly alter movement, diet, attack, defense, and ability options. This makes Cell feel like an organism-building stage instead of a top-down food arena.
4 Creature creator Body sculpting, part placement, paint, and animation preview feel complete. The Creature stage depends on DNA and part verbs being meaningful.
5 Creature world Nests, species, food, socialization, combat, and migration create a true stage loop. Once verbs exist, the world can reward them coherently.
6 Polish and QA Audio, camera, UI, accessibility, performance, and tests lock the experience down. This turns the systems into a shippable-feeling game mode set.

Audit Notes By Area

Cell Mode

Strong amount of authored content and ecological intent. Highest leverage is restoring the growth/evolution trigger path, then making organelles visual, discoverable, and multiplayer-safe.

Creature Creator

Good DNA/editor skeleton with undo and part catalogs. Needs body sculpting depth, curated part data, animation preview, paint, and an actual return-to-game lifecycle.

Creature Game Mode

Readable action controller and encounter systems are in place. Needs a world loop: nest, diet, species relationships, social and combat routes, migration, and editing milestones.

Multiplayer

The project has more multiplayer ambition than the reference game. Keep it. Make the host authoritative over shared ecology and progression so co-op feels like an upgrade, not a risk.

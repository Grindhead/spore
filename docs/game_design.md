# Game Design - Project Spore (RoobsWorld)

Summary for designers and implementation.

## Vision

A Spore-inspired evolution sandbox focused on two stages only:

- Cell stage
- Creature stage

All later stages are intentionally removed from scope.

## Stages

| Stage | Genre | Camera |
|---|---|---|
| Cell | Top-down arcade | 2D orthographic |
| Creature | Third-person action | 3D follow |

## Core Systems

- Procedural creature editor with stats-driven parts
- Procedural world generation for cell and creature gameplay
- Evolution and progression via DNA and mutation
- Save/load with persistent player progression

## Target Platforms

PC (Steam), PlayStation, Xbox, Nintendo Switch.
